Why ZMDB?

ZMDB is a high-performance key-value database written in Zig, specifically designed for mobile devices. While SQLite focuses on raw speed, ZMDB focuses on what matters most for mobile: battery life.

🔋

Battery Efficient

99% fewer wake-ups than SQLite. Your users' batteries will thank you.

🌡️

Thermal Aware

Automatically throttles when device gets hot. Prevents overheating.

⚡

Charging Aware

Does expensive work when plugged in. Smart scheduling.

🗜️

Adaptive Compression

50-80% storage reduction. Less I/O means better battery.

🚀

LSM-Tree Architecture

Sequential I/O optimized for mobile flash storage.

🔒

Type Safe

Written in Zig. Compile-time guarantees. 60x simpler than SQLite.

ZMDB vs SQLite

Feature ZMDB SQLite
Wake-ups (1000 writes) 1-10 100
Idle Battery Drain 0% ~0.5%/hr
Thermal Awareness ✓ Built-in ✗ None
Charging Detection ✓ Adaptive ✗ None
Code Size 2.5K LOC 150K LOC
Binary Size ~100KB 1-2MB
Raw Speed 110K writes/sec 625K writes/sec
SQL Support KV only Full SQL

Quick Start

// Clone the repository
git clone https://github.com/AmritRai1234/ZDB.git
cd ZDB

// Build for Android
./build_android.sh

// Build for iOS
./build_ios.sh

// Run tests
zig build test

// Run benchmarks
zig build bench-battery
